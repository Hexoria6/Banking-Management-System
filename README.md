# Banking-Management-System
🏦 Banking Management System

📌 Project Overview

A Python-based Banking Management System designed to demonstrate banking operations through a graphical user interface. This project combines Python programming, database management, and data visualization.

🛠️ Technologies Used

* Python — Core programming language
* Tkinter — Graphical user interface
* SQLite — Database management
* Pandas — Data handling
* NumPy — Numerical computations
* Matplotlib — Data visualization

✨ Key Highlights

* Graphical interface built with Tkinter
* Database integration using SQLite
* Organized Python functions
* Data analysis and visualization

📂 Project Files

* Banking Management System.py — Main Python source code
* Output-1.png to Output-5.png — Project output screenshots

▶️ How to Run

1. Install Python.
2. Download this repository.
3. Install any missing dependencies: Pandas, NumPy, and Matplotlib.
4. Open the project folder in VS Code.
5. Run:
    python "Banking Management System.py"

🎯 Project Objective

To demonstrate practical Python programming skills, GUI development, database integration, and data visualization.
